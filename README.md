# 🏫 Oakridge International Academy - School Website Template

A modern, mobile-first school landing page designed with an **Emerald & Coral** aesthetic. Built for modern educational institutions, high schools, and academies.

## ✨ Features
- **Modern UI & Aesthetic:** Built with Tailwind CSS and Plus Jakarta Sans typography.
- **Interactive Admission Form:** Multi-step tabbed application form powered by Alpine.js.
- **Filterable Gallery:** Categorized grid for campus labs, sports facilities, and events.
- **Direct WhatsApp Integration:** Quick campus tour booking form linked directly to WhatsApp.
- **Interactive FAQ Accordion:** Clean parent query dropdowns.
- **Contact & Map Section:** Office hours, location badge, and general inquiry form.

## 🛠️ Tech Stack
- **HTML5**
- **Tailwind CSS** (CDN)
- **Alpine.js** (Interactivity & State Management)
- **FontAwesome 6** (Icons)
